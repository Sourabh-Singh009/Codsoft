# CodSoft Java Programming Internship

This repository contains Java mini-projects completed during my 4-week Java Programming internship at CodSoft.

## Projects

### 1. Number Game
A simple number guessing game built in Java to practice loops, conditionals, and random number generation.

### 2. Student Grade Calculator
A program that calculates student grades based on marks entered, using conditional logic.

### 3. ATM Interface
A console-based ATM simulation covering deposit, withdrawal, and balance check operations, demonstrating basic banking logic in Java.

## Tech Stack
- Java (Core concepts: OOPs, loops, conditionals, methods)

## About the Internship
Completed as part of a 4-week virtual internship focused on strengthening core Java programming skills through practical, project-based learning.
